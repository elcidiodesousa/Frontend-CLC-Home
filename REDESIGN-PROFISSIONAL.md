# Redesign profissional do frontend

Alterações principais:

- Fonte Manrope através do Google Fonts.
- Material Icons Round carregados pela internet.
- Sidebar corporativa, responsiva e organizada por secções.
- Topbar com pesquisa, notificações e perfil.
- Nova landing page institucional.
- Login e registo redesenhados.
- Sistema global de cores, sombras, espaçamentos e formulários.
- Tipografia reduzida e mais equilibrada.
- Melhor adaptação para computador, tablet e telemóvel.

## Executar

```powershell
npm install
npm start
```

O backend continua em `http://localhost:8080/api` e o frontend em `http://localhost:4200`.
